## كيف تُشغّل

```bash
npm test            # من الجذر
npm -w apps/api run test
```
الاختبارات تنشئ قاعدة معزولة في `apps/api/.data/test-pglite` وتمسحها في كل تشغيل.

## ثغرات يجب سدّها قبل الإنتاج (بوابة جودة)

1. اختبارات أداء (≥ 300 مستخدم متزامن، p95 < 800ms للقراءة و< 1.5s للكتابة).
2. SAST (Semgrep/CodeQL) + `npm audit` + فحص صور Docker في CI.
3. اختبار اختراق خارجي (Web + API + RLS bypass attempts).
4. تجربة استعادة فعلية موثقة تحقق RPO/RTO.
5. E2E (Playwright) للعربية/RTL وسيناريوهات الأخطاء.
6. UAT موثق من الاستقبال/التمريض/المختبر/الصيدلية/المالية.

> الشروط في الأعلى **لم تُنفَّذ بعد**، ولا يُعد النظام جاهزًا للإنتاج قبلها.
